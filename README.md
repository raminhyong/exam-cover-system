# ระบบพิมพ์ปกซองข้อสอบ — โรงเรียนพูลเจริญวิทยาคม

เว็บแอปพลิเคชันสำหรับจัดทำและพิมพ์ปกซองข้อสอบวัดผล (ข้อสอบปรนัยและอัตนัย) โรงเรียนพูลเจริญวิทยาคม ทำงานแบบ Single File HTML โดยไม่ต้องพึ่งพาเซิร์ฟเวอร์หรือฐานข้อมูลภายนอก (บันทึกข้อมูลผ่าน LocalStorage ภายในเครื่อง)

---

## 📌 ข้อมูลรอบการสอบปัจจุบัน
* **ภาคเรียนที่:** 2
* **ปีการศึกษา:** 2569
* **ประเภทการสอบ:** กลางภาค (21 – 24 ธันวาคม 2569)
* **จำนวนห้องสอบ:** 72 ห้อง (ระดับชั้น ม.1/1 – ม.6/9)
* **จำนวนรายวิชาสอบ:** 86 รายการ (ม.1 – ม.6 ปรับปรุง 20/11/69)

---

## ✨ ฟีเจอร์หลัก
1. **สร้างปกซองข้อสอบ (ปรนัย):**
   * เลือกวิชาจากตารางสอบ ระบบจะดึงรหัสวิชา ชื่อวิชา วันที่ เวลา และห้องสอบที่เกี่ยวข้องขึ้นมาให้อัตโนมัติ
   * กำหนดจำนวนข้อสอบ คะแนนเต็ม ครูผู้สอน และกรรมการคุมสอบประจำห้อง
   * รองรับการใส่ข้อสอบชุด A / ชุด B
   * สร้างปกซองพร้อมแบบฟอร์มบันทึกการส่งข้อสอบและลายมือชื่อกรรมการ
2. **พรีวิว & พิมพ์ปกซองข้อสอบ:**
   * จัดเรียงแบบ A4 พอดีหน้า พร้อมพิมพ์ลงเครื่องพิมพ์หรือบันทึกเป็น PDF
3. **พรีวิวปกข้อสอบอัตนัย:**
   * สร้างใบปะหน้าสำหรับข้อสอบอัตนัยตามมาตรฐานของโรงเรียนด้วย HTML/CSS
4. **ระบบผู้ดูแลระบบ (Admin Panel):**
   * รหัสผ่านเข้าใช้งานเริ่มต้น: `123456` (เข้าผ่านปุ่ม 🔒 จัดการระบบ หรือคีย์ลัด `Ctrl+Shift+A`)
   * ตั้งค่าเอกสารเริ่มต้น (ภาคเรียน, ปีการศึกษา, ประเภทการสอบ)
   * จัดการและนำเข้าข้อมูลห้องสอบ (รองรับไฟล์ `.csv`)
   * จัดการและนำเข้าตารางสอบวิชา (รองรับไฟล์ `.csv`)
   * จัดการฐานข้อมูลรายชื่อครูผู้สอนและกรรมการคุมสอบ

## 📁 โครงสร้างโปรเจกต์
```text
.
├── index.html                           # ระบบพิมพ์ปกซองข้อสอบหลัก (Single-file Web App)
├── school logo.png                      # โลโก้โรงเรียนพูลเจริญวิทยาคม
├── ปกซองข้อสอบ bg new.png               # ภาพพื้นหลังแบบฟอร์มปกซองข้อสอบ
├── ข้อมูลตารางสอบ/
│   └── 2569-2/                          # ข้อมูลภาคเรียนที่ 2/2569
│       ├── 2_2569 (1).md                # ตารางสอบวิชา (ฉบับปรับปรุง)
│       ├── 2_2569 (2).md                # ตารางจัดห้องสอบ 72 ห้อง
│       ├── ตารางสอบ_2569_2.csv          # ตารางสอบวิชา 86 รายการ (CSV)
│       ├── ห้องสอบ_2569_2.csv           # ตารางห้องสอบ 72 ห้อง (CSV)
│       ├── exam_schedule_2_2569.json    # ตารางสอบวิชา (JSON)
│       └── exam_rooms_2_2569.json       # ตารางห้องสอบ (JSON)
└── คณะกรรมการคุมสอบ/
    └── 2569-1 กลางภาค.json              # ฐานข้อมูลรายชื่อครูและกรรมการคุมสอบ
```
